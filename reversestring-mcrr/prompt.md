Actúa como un programador experto en desarrollo web y crea una página web sencilla que invierta una cadena de texto.

Por ejemplo:
Si el usuario escribe ABCDEF, la página debe mostrar FEDCBA.

Requisitos:

Usa únicamente HTML y JavaScript (no utilices frameworks ni librerías externas).

Separa el código en dos archivos:

index.html

script.js

La página debe incluir:

Un campo de texto donde el usuario pueda escribir una palabra o frase.

Un botón para invertir el texto.

Un área donde se muestre el resultado con la cadena invertida.

El archivo index.html debe enlazar correctamente con script.js.

El código debe ser claro, simple y bien organizado, pensado para que un principiante pueda entenderlo fácilmente.

Incluye comentarios en el código explicando qué hace cada parte.

Entrega:

El código completo de index.html.

El código completo de script.js.
